<summary>⚙️ One-time setup for the snake animation (click to expand)</summary>

<br>

The snake animation isn't a static image — it's generated by a GitHub Action that redraws your contribution graph as a snake eating each square, and needs to run once to create the `output` branch it points to:

1. In your `donempudi-prudhvi/donempudi-prudhvi` repo, go to **Actions → New workflow → set up a workflow yourself**.
2. Paste in the workflow from https://github.com/Platane/snk (README has the exact YAML — copy the "Generate the snake" example).
3. Commit the workflow file (e.g. `.github/workflows/snake.yml`) and run it once manually (**Actions → your workflow → Run workflow**).
4. It'll create an `output` branch with the SVG the README already points to above — no further changes needed after that; it auto-updates daily.

</details>
